# FR ENCUTIDOS — LANDING PAGE BRIEF

## OBJETIVO DEL PROYECTO

Diseñar y desarrollar una landing page enfocada en conversión para FR Encurtidos.

El objetivo principal es generar consultas y ventas mediante WhatsApp.

---

# PRIORIDAD

La prioridad absoluta es la conversión.

Toda decisión de diseño debe favorecer:

* Contacto por WhatsApp.
* Consulta de productos.
* Pedido de encurtidos.

---

# TIPO DE SITIO

Landing Page One Page.

Navegación mediante scroll.

Mobile First.

---

# ESTRUCTURA

## 1. HERO

Debe incluir:

* Nombre de la marca.
* Imagen principal.
* Mensaje principal.
* CTA a WhatsApp.

Objetivo:

Comunicar inmediatamente qué vende la marca.

---

## 2. ABOUT

Explicar:

* Proceso artesanal.
* Selección de ingredientes.
* Producción cuidada.
* Calidad del producto.

Objetivo:

Generar confianza.

---

## 3. PRODUCTOS

Mostrar:

### Berenjenas Encurtidas

* Imagen.
* Nombre.
* Descripción.

### Morrones Encurtidos

* Imagen.
* Nombre.
* Descripción.

Objetivo:

Mostrar claramente la oferta.

---

## 4. CTA FINAL

Sección enfocada en conversión.

Debe incluir:

* Mensaje persuasivo.
* Botón WhatsApp.

Objetivo:

Generar acción inmediata.

---

## 5. FOOTER

Debe incluir:

* Email.
* Instagram.
* WhatsApp.

Objetivo:

Ofrecer múltiples vías de contacto.

---

# UX

Mobile First obligatorio.

La experiencia debe ser:

* Clara.
* Rápida.
* Intuitiva.
* Escaneable.

El usuario debe comprender en menos de 5 segundos:

* Qué vende la marca.
* Qué productos ofrece.
* Cómo comprar.

---

# UI

Estética:

* Artesanal.
* Premium.
* Gastronómica.
* Moderna.

Inspiración:

* Marcas gourmet.
* Productos delicatessen.
* Conservas artesanales.

Utilizar:

* Mucho espacio negativo.
* Tipografía con personalidad.
* Fotografía de producto protagonista.
* Jerarquía visual fuerte.

---

# COMPONENTES

Componentes reutilizables:

* Navbar fija.
* Botones CTA.
* Cards de producto.
* Secciones de contenido.
* Footer.
* Botón flotante para volver arriba.

---

# PERFORMANCE

Objetivos:

* Lighthouse superior a 90.
* Optimización de imágenes.
* Lazy Loading.
* CSS limpio.
* HTML semántico.

---

# SEO

Implementar:

* HTML semántico.
* H1 único.
* H2 para secciones.
* Meta Title.
* Meta Description.
* Open Graph.
* Alt text descriptivos.

---

# CONVERSIÓN

Todo CTA principal debe apuntar a WhatsApp.

Priorizar:

* Visibilidad.
* Claridad.
* Simplicidad.

No agregar elementos que distraigan del objetivo principal.

La conversión tiene prioridad sobre la decoración.
